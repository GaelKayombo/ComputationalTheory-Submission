# Computational Theory Assessment

This repository contains my submission for the Computational Theory module assessment.

The assessment is completed using Python in a Jupyter notebook called problems.ipynb.

# Running the Notebook

The notebook can be opened and run using GitHub Codespaces.

Open the repository on GitHub.

Click the green Code button.

Select Codespaces and open a Codespace.

Open problems.ipynb in Visual Studio Code.

Select the Python kernel.

Run the notebook cells using the play buttons or Run All.
